# hdr-admin-web

`hdr-admin-web` is reserved for the future METT HDR Admin Web.

## Planned Admin Capabilities

- User management
- Membership and orders
- Product review
- Product parameter templates
- Rules management
- Report management
- File metadata management
- Expert display management
- Tutorial management
- Integration logs
- Audit logs
- Job monitoring
- Lighting module configuration

No admin frontend implementation is included in this PR.
