# Development Roadmap

## First-Stage Development Order

- Sprint 0: Technical architecture confirmation and project startup
- Sprint 1: Java backend foundation
- Sprint 2: Authentication and user foundation
- Sprint 3: Team, organization, and resource ownership
- Sprint 4: Membership benefits and quota system
- Sprint 5: Payment and order foundation
- Sprint 6: Project and space foundation
- Sprint 7: File, report, and async job foundation
- Sprint 8: Product health performance database and parameter templates
- Sprint 9: Rules and matching foundation
- Sprint 10: Expert, tutorial, and evaluation backend integration foundation
- Sprint 11: Lighting module MVP backend
- Sprint 12: Integration hardening and internal beta preparation

The lighting module must not be developed as an isolated tool.

It must be built on top of the HDR platform foundation.
