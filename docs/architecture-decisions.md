# Architecture Decisions

## Accepted Decisions

- ADR-001: METT HDR is an independent platform.
- ADR-002: METT HDR backend uses Java.
- ADR-003: Modular monolith first, not microservices first.
- ADR-004: MySQL 8 is the primary relational database.
- ADR-005: Redis is used for cache/session/task support.
- ADR-006: Files use metadata-first model with object storage.
- ADR-007: App API, Admin API, and Integration API must use separate authentication models.
- ADR-008: Global IDs must be used for cross-system objects.
- ADR-009: Reports must store version snapshots.
- ADR-010: Evaluation backend integration is read-only in the current baseline.
